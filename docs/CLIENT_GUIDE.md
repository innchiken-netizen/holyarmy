# Guide d'Utilisation Client — Portail Ministère (`/dashboard`)

## 1. Créer une Demande Créative (`/dashboard/requests/new`)
1. Cliquez sur le bouton orange **"Nouvelle demande"**.
2. Renseignez le thème du culte ou de la série (ex: "Culte de Pâques 2027").
3. Sélectionnez le type d'asset souhaité (visuel dominical, motion flyer 9:16, clip prédication).
4. Indiquez vos formats, la date de diffusion et le passage biblique.
5. Cliquez sur **"Transmettre à holy.army"**.

## 2. Valider un Livrable (`/dashboard/deliverables`)
1. Dès que notre directeur artistique a finalisé l'aperçu, une notification apparaît sur votre tableau de bord.
2. Ouvrez `/dashboard/deliverables` depuis votre mobile ou votre ordinateur.
3. Si le visuel est parfait : cliquez sur **"Approuver"** pour recevoir les fichiers HD définitifs.
4. Si un ajustement est requis : cliquez sur **"Ajuster"** et formulez votre remarque.

## 3. Configurer votre Bio-Page Pasteur (`/dashboard/profile`)
1. Choisissez l'un des 3 modèles graphiques : Minimal Editorial, Bold Ministry ou Executive Pastor.
2. Définissez votre identifiant unique (ex: `holy.army/pasteurpaul`).
3. Renseignez vos liens de culte en direct, votre lien de don sécurisé et votre WhatsApp.
4. Activez le statut **"Publié"** pour le rendre accessible à toute votre communauté.
